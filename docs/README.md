## Evidence

Generated figures and their contributing-run indexes live under:

- [`figures/pretrained/`](figures/pretrained/) - current ImageNet-initialized
  ResNet50 comparison at k=20/50/100.
- [`figures/scratch/`](figures/scratch/) - scratch and imported historical
  cohorts for ResNet50 and ViT.

Each directory contains a `runs.csv` generated by
`src/graphs/plot_graphs.py`. Treat `runs.csv` and the underlying
`results/comparison_v1/**/summary.json` files as the evidence indexes; do not
read values back from the pixels of a plot.

## Documentation Ownership

- Root `README.md`: onboarding, setup, and common commands.
- `architecture.md`: stable system design and artifact flow.
- `reproducibility.md`: what is required to reproduce or extend a run.
- `resnet_comparison_v1.md`: the scientific comparison recipe.
- `project_status.md`: date-sensitive inventory, results, limitations, and
  next tasks.
- `presentation_outline.md`: communication guidance derived from current
  status; not a source of truth for result values.

When results change, regenerate the figures first, update
`project_status.md`, and then revise presentation material.
